DeskClear 1.0.5 便携版
========================

1. 请先「全部解压」到一个文件夹，再使用。不要只从压缩包里拖出 exe（缺少 dll 无法运行）。
2. 解压后 DeskClear.exe 会显示应用图标，可把它或整个文件夹放到桌面。
3. 双击 DeskClear.exe 运行。dll 和 platforms 必须与 exe 放在同一文件夹。

要求：64 位 Windows 10/11。

特别注意：软件本身是安全的，但程序属于全新的小众文件，没有在微软云端积累足够的“安全信誉”，也没有经过数字签名认证，就会被系统判定为“无法识别的潜在风险应用”进行拦截。

解决方法：
1.找到你从GitHub下载下来的这个程序exe文件
2.右键点击文件，选择底部的「属性」选项
3.在弹出的属性窗口的常规选项卡最底部，会看到一个「安全」区域
4.勾选「解除锁定」复选框，点击「应用」再点击「确定」
  完成这个操作后，后续直接双击程序就能正常打开，不会再触发SmartScreen拦截。
